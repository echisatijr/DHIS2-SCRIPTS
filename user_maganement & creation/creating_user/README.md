# Creating User

This script creates DHIS2 users in bulk from a district user file.

## What it does

The script:

1. reads the district user list from an Excel file
2. reads the district catchment-area list from another Excel file
3. matches each user to the correct CA or facility using fuzzy matching
4. generates a username and password
5. checks for existing usernames and already-created users
6. creates each user in DHIS2
7. exports a created-user report to an Excel file

## Why this matters

This is the main user onboarding workflow. It turns a plain list of CHWs into DHIS2 platform users with the correct organisation unit assignment.

## Expected input files

The script expects two files in the data folder:

- {district}_users.xlsx
- {district}_CA.xlsx

Example:

```text
../data/Balaka_users.xlsx
../data/Balaka_CA.xlsx
```

## Expected input columns

### User file

```text
User Full Name,orgUnitName,Facility,Phone Number,Email,userRole,userGroup
```

Example:

```text
User Full Name,orgUnitName,Facility,Phone Number,Email,userRole,userGroup
Agatha Zidana,Guzani CA (Tongozala Health Centre),Tongozala Health Centre,997067436,agatha@example.com,K7DkWdiGSbA,GroupUID
```

### CA file

This file is typically generated by the CA Pulling script and should include:

```text
name,id,level,parent_name,parent_id
```

## Output file

The created user report is saved as:

```text
../data/{district}_created_users.xlsx
```

Example:

```text
../data/Balaka_created_users.xlsx
```

## Expected output columns

```text
Catchment Area,CA UID,CHW Fullname,Phone Number,Facility Name,Username,Password
```

Example:

```text
Catchment Area,CA UID,CHW Fullname,Phone Number,Facility Name,Username,Password
Guzani CA (Tongozala Health Centre),tv21Cm2Q9EP,Agatha Zidana,997067436,Tongozala Health Centre,agathazidana,Azidana@2026
January CA (Chioshya Health Centre),Qk36Nb1QV64,Alinafe Grace Chidya,886424505,Chioshya Health Centre,achidya,Achidya@2026
```

## Additional behavior

- It avoids re-creating users already saved in the created-users file.
- It generates usernames from the full name.
- It generates a password using the first letter of the first name and the last name, plus the current year.
- It assigns the correct organisation unit and saves the created-user report.

## Notes

This is the main script for bulk creation of community health worker accounts in DHIS2.

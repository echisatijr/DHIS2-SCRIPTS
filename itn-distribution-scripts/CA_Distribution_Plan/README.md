# ITN Distribution Planning System

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)

Tool for generating insecticide-treated net (ITN) distribution plans based on household registration data.

## Features

- Automatic detection of latest CSV data file
- Household-level net requirement calculations
- Catchment area/HSA-level summaries
- Bale packaging calculations (50 nets/bale)
- Multi-sheet Excel output

## Requirements

- Python 3.8+
- Dependencies: `pandas`, `pydash`
